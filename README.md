# Knowhere Systems

Next.js 16 website for Knowhere Systems — IT services agency in Hyderabad, Pakistan.

## Stack

- Next.js 16 (App Router) + Turbopack
- React 19
- TypeScript
- Custom CSS (ported design system)

## Develop

```bash
cd knowhere
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Routes

| Path | Page |
|------|------|
| `/` | Home |
| `/services` | 12 IT service disciplines |
| `/work` | Case studies |
| `/about` | Company |
| `/contact` | Contact form |
